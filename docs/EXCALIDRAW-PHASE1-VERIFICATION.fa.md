# گزارش فاز اول Excalidraw

تاریخ: 2026-11-11 — نتیجه: build و صفحه آزمایشی مستقل آماده‌اند.

## نسخه‌ها و خروجی

- Node محلی 22.23.4 با بررسی SHA256 آرشیو رسمی.
- Excalidraw 0.18.1، React و ReactDOM 18.3.1؛ نسخه‌ها دقیق و وابستگی‌ها در lockfile ثبت شده‌اند.
- Vite 8.3.8 و TypeScript 7.0.2؛ بررسی TypeScript پیش از build اجرا می‌شود.
- خروجی محلی در `wwwroot/vendor/whiteboard/`، شامل CSS، chunkها، فونت‌ها و THIRD-PARTY-NOTICES.txt. طبق تصمیم کاربر خروجی در Git نادیده گرفته می‌شود؛ سورس و lockfile مبنای بازسازی‌اند.

## بررسی‌های انجام‌شده

- نصب پاک `npm ci --offline` با cache محلی موفق: 280 بسته، بدون دانلود شبکه. نصب اولیه روی دستگاه جدید اینترنت لازم دارد.
- build پس از نصب پاک و بررسی TypeScript موفق.
- صفحه از سرور موجود .NET در `http://localhost:5080/vendor/whiteboard/index.html` پاسخ 200 داد.
- تست Chrome بدون پنجره روی همین سرور: mount موفق، رسم مستطیل، ورود متن فارسی، تغییر حالت مشاهده و مخفی‌شدن ابزار رسم، اندازه صفحه 390×844.
- شبکه مرورگر با مسدودکردن درخواست‌های خارج از سرور محلی بررسی شد: درخواست خارجی و exception اجرایی ثبت نشد؛ 10 درخواست فونت محلی مشاهده شد.
- تصویر `.run/whiteboard-phase1.png` بازبینی شد؛ شکل و متن فارسی دیده می‌شوند. جزئیات درخواست‌ها در `.run/whiteboard-phase1-result.json` و لاگ build در `.run/whiteboard-build.log` موجود است. فایل‌های `.run` موقتی و خارج از Git هستند.

## محدودیت‌ها

صفحه مستقل و حافظه‌ای است؛ اتصال به نشست، مجوز سروری، API v2، ذخیره، LiveKit و ضبط هنوز انجام نشده‌اند. تست Smoke کلاس برای این فاز اجرا نشد. حالت مشاهده امکان جابه‌جایی نمای بوم دارد؛ تغییر تصویر ناشی از pan به معنای ویرایش scene نیست.

Build هشدار اندازه chunk و directiveهای client وابستگی‌ها دارد؛ build موفق است. npm برای وابستگی گذرای sliced هشدار deprecated می‌دهد. ارزیابی امنیت و ظرفیت بخشی از این تست نبوده است.

بعد از clone اجرای `scripts/setup-whiteboard.ps1` لازم است؛ setup اصلی دمو در این فاز تغییر نکرده است. دستور اجرا و بازسازی در [راهنمای تخته](../frontend/whiteboard/README.fa.md) آمده است.
