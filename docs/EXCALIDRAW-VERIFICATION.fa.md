# بررسی نهایی اتصال Excalidraw

تاریخ: 2026-11-11 — وضعیت: گام‌های ۱ تا ۷ MVP پیاده‌سازی و نسخه فعلی دوباره بررسی شد.

## نتیجه بررسی پس از قطع ارتباط

کد اصلی در کامیت `9af2e2c` موجود بود. مستندات هنوز وضعیت فاز اول را نشان می‌دادند و آخرین تغییرات اعتبارسنجی و تست ضبط نیاز به اجرای مجدد داشتند. build، تست‌های زیر و گزارش وضعیت تکمیل شدند. سورس برنامه برای رفع خطای تازه نیاز به تغییر نداشت؛ تست مرورگر برای حذف همه محتوا و رسم پیوسته گسترش یافت.

## بررسی‌های موفق نسخه فعلی

| بررسی | نتیجه |
| --- | --- |
| build فرانت و TypeScript | موفق؛ خروجی، فونت و مجوزها محلی ساخته شدند |
| build .NET | موفق؛ بدون warning و error |
| `tests/Whiteboard` | اعتبارسنجی scene، محدودیت تعداد، شناسه تکراری، binding خراب، مهاجرت و backup دقیق، عدم overwrite فایل خراب |
| `tests/WhiteboardApi` | 401/403، schema قدیمی و ناشناخته، JSON نامعتبر، نوع غیرمجاز، لینک، appState اضافی، عمق، سقف بدنه و Snapshot، 409، جداسازی اتاق، انقضای lease و جلوگیری از تمدید مجوز واگذارشده |
| `tests/Smoke` | دو Chrome واقعی، چت و دست‌بالابردن، صوت و تصویر، همگام‌سازی رسم و متن فارسی با polling فراگیر خاموش، اشتراک صفحه و بازگشت، refresh، ضبط و دانلود واقعی |
| `tests/whiteboard-browser.mjs` | متن فارسی، شکل، فلش، قلم، undo/redo، حذف همه و refresh تخته خالی، ذخیره حین رسم پیوسته، عدم ذخیره selection/viewport، PUT سریالی، GET دیررس و حفظ تغییرات در خطا |
| restart واقعی بک‌اند | scene و revision قبل از توقف ذخیره و پس از راه‌اندازی مجدد با نشست جدید بازیابی شدند |
| Git | خروجی `wwwroot/vendor/whiteboard/` همچنان ignore است؛ `git diff --check` موفق |

تست مرورگر تکمیلی با شبیه‌سازی PUT کند، خطای شبکه، 413 و 403 اجرا شد. 409 با یک درخواست HTTP جدا که revision سرور را جلو می‌برد ایجاد شد. در قطع شبیه‌سازی‌شدهٔ بک‌اند، ویرایش متوقف و تغییر محلی نگهداری شد؛ پس از بازیابی، ذخیره موفق بود. درخواست خارجی asset و exception اجرایی در هر دو مرورگر ثبت نشد؛ فونت‌ها از سرور خود برنامه دریافت شدند.

## ضبط و بازبینی تصویر

WebM در مرورگر ضبط، روی سرور ذخیره و از مرورگر دانلود شد؛ بایت‌های دانلود با فایل ضبط یکسان بودند. فایل در اندازه 1280×720 پخش و صدای آن با نمونه‌های غیرساکت decode شد. چت در متن رندرشده ضبط نبود. تصاویر پخشِ اشتراک صفحه و سپس تخته بازبینی شدند؛ مستطیل و متن «سلام؛ تخته کلاس فارسی» در فریم تخته دیده می‌شوند.

خروجی‌های موقت در `.run` هستند: `excalidraw-smoke.log`، `whiteboard-api.log`، `whiteboard-browser.log`، `whiteboard-browser-result.json`، `whiteboard-build.log`، `demo-recording.webm`، `demo-recording-playback.png`، `demo-recording-whiteboard.png` و `excalidraw-learner-mobile.png`. این فایل‌ها در Git نگهداری نمی‌شوند. فرمان‌های تکرار تست در [راهنمای فرانت](../frontend/whiteboard/README.fa.md) آمده‌اند.

## محدوده اعتبار نتایج

- انتخاب پنجره اشتراک در Smoke با Canvas capture جایگزین شده؛ ارسال و دریافت رسانه از LiveKit واقعی است. انتخاب پنجره سیستم‌عامل باید دستی بررسی شود.
- قطع طولانی شبکه واقعی، reconnect ناشی از آن، شروع مرورگر با فونت عمداً کند و توقف واقعی LiveKit در میانه کلاس در این بررسی اجرا نشدند. خطای fetch در تست، شبیه‌سازی است.
- build دوباره با وابستگی‌های نصب‌شده اجرا شد؛ نصب پاک offline از cache در فاز اول تأیید شده بود. نصب کامل از صفر روی دستگاه دیگر این بار اجرا نشد.
- آزمون ظرفیت ۳۰۰ نفر، بررسی production و ممیزی امنیت انجام نشده است. MVP همچنان فقط یک نویسنده دارد.
- build فرانت هشدارهای غیرمسدودکننده درباره اندازه chunk و directive وابستگی‌ها دارد؛ build موفق است.

راهنمای setup، ذخیره و rollback به‌روز شده است. دمو پس از بررسی روشن است: `http://localhost:5080`.
